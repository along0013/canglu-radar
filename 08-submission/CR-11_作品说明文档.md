# CR-11｜舱路雷达作品说明文档

## 1. 项目概述

舱路雷达是一个面向跨境电商物流运营的异常预警与发货决策情报系统，目标是把物流专员每周 3-4 小时的运价查询、成本测算和建议撰写，压缩为 10-20 分钟的自动化复跑流程。项目围绕 SCFI 运价、船公司公告、汇率与附加费场景，形成“指标计算 → 差异化建议 → 分析报告 → 展示材料 → 复跑验证”的闭环，最终输出可审查的 Markdown 报告、Excel 指标表、PPT/长图素材和提交包。

---

## 2. 场景真实性与闭环验证（35%权重）

### 2.1 真实业务场景

跨境电商物流运营每周需要回答三个问题：

1. 哪些航线进入高位或异常波动？
2. 本周报价、订舱和发货节奏应如何调整？
3. 如果汇率、附加费、拥堵因素变化，成本会如何变化？

舱路雷达将这些问题拆成可复跑的数据链路，并在 `03-analysis/CR-04A_指标计算结果.xlsx`、`04-decision-report/CR-04B_业务决策建议.md`、`04-decision-report/CR-05_分析报告.md` 中给出可验证结果。

## 3. 商业价值与可持续性（30%权重）

### 3.1 效率提升

传统人工流程通常包括查网页、整理 Excel、换算汇率、判断航线风险、写报告和做展示材料。舱路雷达把这些动作拆为可复跑链路，目标效率为：

| 环节 | 人工方式 | 舱路雷达方式 | 代表文件 |
|---|---|---|---|
| 数据收集 | 每周查多个网站、公告和汇率源 | 读取标准化 CSV / Excel 输入 | `01-raw-data/`、`02-processed-data/` |
| 指标计算 | 人工维护 Excel 公式、透视表 | 自动计算分位、环比、Z 分数、连续上涨 | `03-analysis/CR-04A_指标计算结果.xlsx` |
| 成本测算 | 手工叠加基础运价、附加费、汇率 | 场景模型统一计算 | `02-governance/surcharge-scenario-cost-model.md`、`04-decision-report/CR-04B_业务决策建议.md` |
| 业务建议 | 依赖资深运营经验 | 规则映射为差异化建议 | `04-decision-report/CR-04B_业务决策建议.md` |
| 报告展示 | 手写周报、整理 PPT | 生成报告、PPT脚本、长图和Demo素材 | `04-decision-report/CR-05_分析报告.md`、`05-presentation/`、`06-visual-demo/` |

效率量化验证框架见 `07-validation/CR-09_量化验证表.xlsx`。其中部分人工耗时字段仍保留 PENDING，表示需要后续真实运营计时补齐；当前提交不将 PENDING 字段升级为已实测结论。

### 3.2 替代环节

| 人工动作 | 系统替代方式 | 文件证据 |
|---|---|---|
| 查 SCFI 与航线价格 | 读取结构化指标源并输出最新周摘要 | `03-analysis/CR-04A_指标计算结果.xlsx` |
| 手动计算环比和异常 | 自动计算 wow_pct、z_score、warning_tags | `03-analysis/CR-04A_指标计算结果.xlsx` |
| 经验判断风险 | 红色预警、P95、Z≥2、连续上涨规则 | `04-decision-report/CR-04B_业务决策建议.md` |
| 手写业务建议 | 按欧洲、地中海、美西、美东、SCFI 生成差异化建议 | `04-decision-report/CR-04B_业务决策建议.md`、`04-decision-report/CR-05_分析报告.md` |
| 手工汇报 | PPT storyboard、HTML deck、长图、Demo脚本 | `05-presentation/CR-06_参赛展示PPT_storyboard.md`、`06-visual-demo/CR-07_闭环长图.png`、`06-visual-demo/CR-08_Demo演示脚本.docx` |

### 3.3 可持续性

项目不是一次性演示稿，而是围绕“每周替换输入 → 复跑指标 → 更新建议 → 输出报告”的机制组织：

1. 输入层保留原始数据、清洗数据和复跑模拟输入；
2. 指标层使用 `CR-04A` 作为唯一数字源，减少口径漂移；
3. 建议层使用 Markdown 输出，便于 Git 审查和 diff；
4. 展示层提供 HTML、PNG、Markdown、DOCX 多种替代材料；
5. 提交层提供 `08-submission/final-package/manifest.csv` 作为材料索引。

### 人工 vs 自动化对比补充

| 对比维度 | 人工操作 | 舱路雷达自动化 | 提升 |
|---|---|---|---|
| 数据收集时间 | 60-90分钟（查5个网站） | 5分钟（读取CSV） | 12-18倍 |
| 计算分析时间 | 45-60分钟（Excel公式+透视表） | 3-5分钟（自动计算） | 12-15倍 |
| 报告撰写时间 | 60-90分钟（整理文字+做PPT） | 5-10分钟（自动生成） | 6-12倍 |
| 易错点 | 公式错误、汇率日期错、单位混淆（TEU/FEU） | 公式固化、单位自动转换、日期自动对齐 | 显著降低 |
| 遗漏率 | 容易漏看某航线公告、漏算某周汇率 | 26周全量扫描，不遗漏 | 从“可能遗漏”到“全量覆盖” |
| 经验依赖度 | 高度依赖资深运营经验判断 | 规则映射+数据驱动，降低对个人经验的依赖 | 可复制 |
| 复用难度 | 每周重新做一遍，无法沉淀 | 每周替换CSV复跑，历史数据自动归档 | 可持续 |
| 决策一致性 | 不同人判断标准不同 | 同一规则，同一输出 | 标准化 |

> 口径说明：以上为基于项目实际运行记录和团队经验估算的单次周度情报生成对比；完整表格见 `07-validation/CR-09_量化验证表.xlsx` 的 `人工vs自动化对比` Sheet。

## 7. 评审速读结论

1. **场景真实**：围绕跨境物流运营每周实际要做的运价查询、成本测算和发货建议展开。

# CR-12｜核心Prompt与多轮调优过程

## 一、核心Prompt原文（5个）

### Prompt 1：项目启动与数据治理

```text
我是跨境电商物流运营，需要每周监控海运运价波动。请帮我设计一个"舱路雷达"系统，要求：
1. 数据来源：SCFI运价指数、船公司公告、汇率、附加费
2. 数据质量分层：A_official（官方）、B_public_excerpt（公开摘录）、C_market_reference（市场参考）、PENDING（待补）
3. 输出：指标计算表、预警标签、差异化建议、成本测算、PPT展示
4. 命名规范：CR-01到CR-10
```

### Prompt 2：指标计算

```text
请基于SCFI运价数据，计算以下指标：
• P95分位、周环比、Z分数（基于26周均值和标准差）
• 连续上涨周数
• 预警标签：P95高位、Z≥2异常、连续上涨≥3周
• 每行标注数据质量等级
输出为Excel，保留公式。
```

### Prompt 3：差异化建议生成（3轮调优）

**第1轮（初稿）：**

```text
请基于指标结果生成发货建议。
```

**第2轮（差异化）：**

```text
建议太笼统。请按欧洲/地中海/美西/美东/SCFI综合分别给出不同建议，每条必须引用具体指标数字。
```

**第3轮（成本场景）：**

```text
请加入成本场景：基础/压力/美东巴拿马压力，并标注数据质量等级。禁止出现"导致""因为"等因果词。
```

### Prompt 4：复跑验证

```text
请基于新的输入数据（Week2: SCFI综合2726.48，Week3: 2985.22）重新运行指标计算和建议生成，记录输入变化和输出变化。
```

### Prompt 5：敏感性分析

```text
请基于最新周数据，生成三张敏感性分析表：
1. 汇率敏感性：USD/CNY从6.8→7.0→7.2
2. 附加费敏感性：基础→压力→极端
3. 运价敏感性：基准→+10%→+20%→+30%
每张表显示公式和计算过程。
```

## 二、多轮调优关键记录

| 轮次 | 问题 | 调优动作 | 结果 |
|:---|:---|:---|:---|
| 1 | 数据不完整 | 从C_demo_simulated升级到A_official真实数据 | Week2用上海航交所2026-06-05真实数据 |

# 关键操作过程说明

由于比赛平台历史对话记录无法导出，以下用文字还原关键操作过程。后续如可补充截图，可将对应截图放入 `06-visual-demo/prompt-process-screenshots/`，并在本文每个操作下追加图片链接。

## 操作1：数据上传与指标计算

- 操作：在小浣熊中上传 `原始_SCFI运价指数.csv`
- Prompt："请读取这份SCFI数据，计算P95分位、周环比、Z分数、预警标签，输出Excel并保留公式。"
- 输出：`03-analysis/CR-04A_指标计算结果.xlsx`
- 调优：要求增加"公式说明"Sheet，确保公式可审计
- 复核点：评审可打开 `CR-04A_指标计算结果.xlsx`，检查 P95、周环比、Z分数、连续上涨周数和预警标签字段

## 操作2：差异化建议3轮调优

- 第1轮：输入"请生成发货建议" → 输出统一建议（被否）
- 第2轮：输入"请按5条航线分别给出不同建议" → 输出初步差异化（部分通过）
- 第3轮：输入"每条建议必须引用CR-04A具体数字，加入成本场景" → 输出最终版 `04-decision-report/CR-04B_业务决策建议.md`
- 关键：从"一刀切"到"5条航线各不相同"，引用 1905 / 3207 / 3154 / 4313 / 2218.15 等核心数字
- 复核点：评审可查看 `CR-04B_业务决策建议.md`，确认欧洲、地中海、美西、美东、综合指数的建议不同

## 操作3：占位稿修复

- 问题：`CR-10A/10B/10C` 的 Word 版曾出现"占位正式稿"风险
- 操作：放弃以 Word 作为主提交形态，改用 Markdown 正式版
- 输出：
  - `08-submission/CR-10A_评委阅读指南.md`
  - `08-submission/CR-10B_复跑说明.md`
  - `08-submission/CR-10C_材料目录.md`
- 调优：删除旧版 Word 和 outline 草稿，避免评委误打开历史版本
- 复核点：Git diff 可审查 Markdown 正式版内容，仓库主线不再保留旧版 CR-10 Word 占位稿

## 操作4：manifest与ZIP一致性修复

- 问题：`manifest.csv` 曾包含 ZIP 自指项，导致清单与实际包不一致
- 操作：删除自指项，重建 ZIP，并核对文件数、空文件和关键文件可读性
- 输出：`08-submission/final-package/舱路雷达-小袁.zip`
- 复核点：最终 ZIP 可正常解压，正式 Markdown 包含在提交材料中，旧版 Word 和 outline 草稿不再进入最终包

## 操作5：真实数据补采

- 操作：搜索并核对上海航运交易所 2026-06-05 真实数据
- 输入：SCFI综合 2726.48，欧洲 2605，地中海 3832，美西 4552，美东 5741
- 输出：Week2 从 `C_demo_simulated` 升级为 `A_official`
- 调优：Week3 综合指数按公开来源处理，分航线按 2026-06-05 真实分航线随综合指数涨幅比例推算，并标注为 `B_public_excerpt`
- 复核点：评审可查看 `09-logs/rerun-records-week2-prime.md` 与 `09-logs/rerun-records-week3-prime.md`，核对输入变化和输出变化

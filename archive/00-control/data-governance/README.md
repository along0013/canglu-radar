# 舱路雷达｜数据采集与分层治理规则入口

本目录用于存放「舱路雷达」项目后续数据补充时必须优先读取的规则文件。规则文件从用户上传的 `output/` 目录复制而来，原文件不删除。

## 文件清单

| 文件 | 用途 |
|---|---|
| `natural-week-multisource-data-governance.txt` | 主规则：自然周级多源物流数据采集与分层治理总办法 |
| `carrier-announcement-natural-week-rules.txt` | 细则一：船公司公告自然周归类与事件抽取 |
| `usd-cny-natural-week-alignment-rules.txt` | 细则二：USD/CNY 汇率自然周对齐与代表值选取 |

## 后续执行原则摘要

1. 以自然周为统一时间颗粒度，优先围绕周一至周日进行归集，而不是只按单日或单一发布时间判断。
2. 数据治理采用分层方式：真实可核验证据、公开转载/行业报道、估算/演示补全应分表或分字段标注，不混用。
3. 船公司公告按公告发布日期、适用生效日期、航线、事件类型等字段抽取，再映射到自然周；不能只看标题。
4. 汇率按自然周对齐，需明确代表值选取逻辑；真实主表与演示补全表应分开。
5. 后续补数时，旧的“只要缺少完整官方证据就整体搁置”的方法应调整为“能确定的字段先分层入库，不能确定的字段保留待核验”。

## 推荐调用顺序

1. 先读 `natural-week-multisource-data-governance.txt`，确认总口径。
2. 如处理船公司公告，读 `carrier-announcement-natural-week-rules.txt`。
3. 如处理汇率，读 `usd-cny-natural-week-alignment-rules.txt`。
4. 再更新对应原始表、统一长表、采集台账和运行日志。

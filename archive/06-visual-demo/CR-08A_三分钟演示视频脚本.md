# 舱路雷达 | 3分钟演示视频脚本

## 镜头1：痛点引入（0:00-0:15，15秒）
- 画面：黑屏白字“每周一，物流专员的小时”。
- 切换：5个浏览器标签（航交所、船公司、汇率、Excel、PPT）。
- 旁白：“每周花3-4小时查运价、算成本、写建议，还容易漏看航线、公式出错。”
- 字幕：3-4小时 → 10-20分钟

## 镜头2：数据上传（0:15-0:35，20秒）
- 画面：小浣熊界面，上传CSV文件。
- 旁白：“把SCFI运价、船公司公告、汇率、附加费规则上传给小浣熊。”
- 字幕：4类数据 → 1个入口

## 镜头3：指标计算（0:35-0:55，20秒）
- 画面：CR-04A指标表，高亮P95、Z分数、预警标签。
- 旁白：“自动计算分位、环比、Z分数、连续上涨周数，每条数据标注质量等级。”
- 字幕：A_official / B_public_excerpt / C_market_reference / PENDING

## 镜头4：差异化建议（0:55-1:20，25秒）
- 画面：CR-04B建议，5个航线卡片依次展开。
- 旁白：“不是统一建议，而是按航线特性定制：欧洲推迟观察、美西提前订舱、美东分批发货。”
- 字幕：5条航线 → 5种策略

## 镜头5：成本测算（1:20-1:40，20秒）
- 画面：三场景成本对比表（基础/压力/巴拿马）。
- 旁白：“基础场景常规报价，压力场景风险缓冲，巴拿马场景单独测算。”
- 字幕：836.50 → 2,111.50 → 2,386.50 USD/FEU

## 镜头6：复跑验证（1:40-2:00，20秒）
- 画面：Week1→Week2→Week3输入输出对比。
- 旁白：“每周替换CSV即可复跑，已验证到2026年6月12日。”
- 字幕：2218.15 → 2726.48 → 2985.22

## 镜头7：量化提升（2:00-2:20，20秒）
- 画面：CR-09对比表，8个维度。
- 旁白：“数据收集12-18倍，指标计算12-15倍，报告撰写6-12倍，决策从因人而异到标准化。”
- 字幕：180-240分钟 → 10-20分钟

## 镜头8：结尾（2:20-3:00，40秒）
- 画面：舱路雷达logo + 一句话定位。
- 旁白：“舱路雷达，让跨境物流决策从经验驱动变成数据驱动。”
- 字幕：每周10分钟，决策更精准

# 技术说明

- 当前提供脚本和分镜，视频因时间限制待补。
- 评审可按CR-10B进行离线材料级复核。
- 脚本中的时间、效率与成本数字对应CR-04A、CR-04B和CR-09中的指标口径。

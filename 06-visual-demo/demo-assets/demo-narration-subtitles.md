# 舱路雷达 Demo 旁白与字幕稿

> 用途：配合 HTML 演示页和截图素材进行现场讲解或后续剪辑。当前素材包不冒充已完成视频成片。

## 00:00-00:40 开场
字幕：舱路雷达把运价指数、汇率、公告和附加费统一成一个可复跑的物流情报闭环。
旁白：本项目面向货代和外贸企业，解决每周看价、查公告、算成本和写建议分散低效的问题。

## 00:40-02:00 数据治理
字幕：A/B/C/PENDING 分层，演示数据不冒充真实数据。
旁白：每一行指标都带质量等级和来源说明，这是为了让评审能追溯数字来源。

## 02:00-04:00 指标预警
字幕：最新周 SCFI 综合 2218.15，五项指标均触发高位或异常预警。
旁白：系统计算分位、周环比、Z分数和连续上涨周数，并给出预警标签。

## 04:00-06:00 差异化建议
字幕：不同航线采用不同业务逻辑，不再一刀切。
旁白：欧洲和地中海按TEU口径关注替代港口，美西关注订舱和报价有效期，美东关注更高成本和路径选择。

## 06:00-07:30 成本测算
字幕：附加费采用场景模型：基础836.50、压力2111.50、美东巴拿马2386.50 USD/FEU。
旁白：附加费不是简单求和，而是按适用场景、触发条件和路径拆分。

## 07:30-09:00 复跑验证
字幕：Week2' 与 Week3' 模拟真实复跑：输入变，输出跟着变。
旁白：我们构造新增周数据，验证系统能响应输入变化，而不是同一批数据重复跑三次。

## 09:00-10:00 结尾
字幕：当前为 MVP 演示闭环，后续可接入真实周度补采与正式PPT/视频交付。
旁白：这个版本证明了闭环和治理能力，下一步重点是真实运营复跑和展示形态完善。

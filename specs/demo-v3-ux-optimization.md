# demo-v3 界面交互优化方案

> 分析日期: 2026-07-02 | 来源: Hermes 完整读取 demo-v3.html (822行) | 状态: 待评审

---

## 总体评估

demo-v3 已具备完整的 H 型驾驶舱骨架（左侧栏 → 中心六 Tab → 右侧事件栏），Dark + Gold 配色专业，数据密度合理。以下 12 条优化按 P1/P2/P3 分级，聚焦**修复缺陷 + 提升路演表现力**。

---

## 🟡 P1 — 影响可用性，建议路演前修复

### #1 AI 聊天区 CSS 类名与 HTML 不一致（🐛 Bug）

**现象**: CSS 定义了 `.ai-chat .ai-label` / `.ai-input` / `.ai-send` 的样式，但 HTML 实际使用的类名是 `chat-header` / `llm-panel` / `llm-head`。这些类名在 CSS 中没有对应规则。

**影响**: 底部 AI 交互区样式完全裸奔，边框/间距/圆角丢失。

**修复**: 二选一——
- 方案 A: 把 HTML 中的类名改为 CSS 中已定义的（`.ai-label`, `.ai-input`, `.ai-send`）
- 方案 B: 在 CSS 中补上当前 HTML 使用的类名

**工作量**: 小（≤10 行）

---

### #2 「风险热力图」是空壳 canvas

**现象**: `<canvas id="heatmapChart">` 在预警分析 Tab 中声明，但 JS 中从未 `new Chart(ctx, ...)` 初始化。

**影响**: 评委切到「⚠️ 预警分析」Tab 时，会看到一个**完全空白的图表区域**，非常刺眼。

**修复**: 
- 方案 A（推荐）: 用 Chart.js 画一个简单的热力矩阵（航线 × 指标：Z分数/WoW/连涨周数），10 分钟可完成
- 方案 B: 路演前先 `display:none` 隐藏该区域

**工作量**: 方案 A 中（~40行 JS）、方案 B 极小（1行 CSS）

---

### #3 Tab 栏在 6 个面板中重复渲染

**现象**: 每个 `tab-*` div 里都内嵌了一份完整的 6 按钮 Tab 栏。HTML 中 Tab 按钮代码出现了 **6 次**（约 60 行重复），且切 Tab 时有视觉跳动（旧 Tab 消失 → 新 Tab 瞬间出现，位置微移）。

**影响**: 代码膨胀 + 路演时切 Tab 体验不够流畅。

**修复**: 将 Tab 栏提取到 `center-top` 顶部只写一份，`switchTab()` 只切换下方的 `.tab-content` 面板。

**工作量**: 中（~30 行 HTML 重构 + 微调 JS）

---

### #4 侧边栏 mini-card 点击 → 趋势图无联动

**现象**: 点击左侧航线 mini-card → 强制切到「航线概览」Tab → 卡片高亮。但中心的趋势图仍然显示全部 5 条曲线，右侧"快速答案"面板很小且静态。

**影响**: 点击的因果链断裂——用户点了一条航线，但看不出"哪条曲线是这条航线"。

**修复**: 
- `renderRouteAnswer()` 被调用时，同步高亮对应 Chart.js dataset（其他曲线 opacity 降至 0.15）
- 快速答案面板加一个短暂的 border flash 动画吸引注意力

**工作量**: 中（~20 行 JS）

---

## 🟠 P2 — 提升专业感和信息密度

### #5 数据源指示灯全绿 → 信息量为零

**现象**: 左侧栏底部 7 个数据源点全是 `.on`（绿色），但索引验证 Tab 明确标注 SCFI/WCI/FBX/BDI 是 `B_public_excerpt` 质量。

**修复**: 按数据质量分层着色：
- A_official → 绿色（CCFI、SCFIS）
- B_public_excerpt → 黄色（SCFI、WCI、FBX、BDI、布伦特）

这样 7 个点本身就是一层信息——评委扫一眼就知道"哪些数据可全信、哪些仅供参考"。

**工作量**: 小（~5 行 JS + 2 行 CSS）

---

### #6 趋势图无交互能力

**现象**: 26 周趋势图一次性展示 5 条线，无 toggle、无 tooltip 增强。

**修复**:
- 点击图例 label → toggle 单条曲线显示/隐藏（Chart.js 默认支持，只需 `legend.onClick` 不拦截）
- tooltip 回调中追加显示 Z 分数（从 ROUTES 数据取）
- 可选：在 01-02 和 06-26 两个时间点加竖虚线标记"半年前 vs 现在"

**工作量**: 中（~15 行 JS）

---

### #7 热点事件无关联航线标签

**现象**: 右侧栏 8 条事件，每条只有日期 + 标题，看不到"影响哪条航线"。

**修复**: 每条事件追加一个航线 pill（如 `#美东` `#地中海` `#全航线`），用事件对应的颜色渲染。点击 pill 跳到对应航线的预警面板。

**工作量**: 中（数据层加 `routes` 字段 + 渲染 ~10 行 JS）

---

### #8 Z 分数缺乏解释入口

**现象**: 整个界面到处是 Z=2.80 / Z=2.59，但对非统计背景的评委，没有一处解释 Z 分数的含义。

**修复**: 在第一个 Z 值旁边加一个 `ⓘ` 图标，hover 显示 tooltip：
> "Z 分数 = (当前值 - 历史均值) / 历史标准差。Z > 2 表示处于统计极端高位，概率 < 5%。"

**工作量**: 小（~5 行 HTML + 8 行 CSS）

---

### #9 痛点 disabled 卡片辨识度不足

**现象**: `disabled`（暂灰）卡片仅靠 `opacity: 0.48` + 虚线边框区分，在深色背景下与实际可用的 `partial` 卡片区别不够大。

**修复**: 
- disabled 卡片左上角加 `🔒 待数据接入` 角标
- 整体加一层细微的 `grayscale(0.6)`（比当前的 0.35 更强）
- 虚线边框颜色从默认 border 改为 `var(--dim2)`

**工作量**: 小（~5 行 CSS + 微调 status-pill 文字）

---

## 🟢 P3 — 锦上添花

### #10 Demo 按钮太简陋

**现象**: `runDemo()` 只是每 2 秒切一个 Tab，无高亮、无动画、无叙事。

**建议**: 改成有故事线的演示序列：
1. 自动展开左侧栏第一条航线 → 高亮该 mini-card + 趋势图对应曲线
2. 切到预警 Tab → 逐个高亮 warning item（红色边框脉冲动画）
3. 切到决策 Tab → 展开第一条决策卡片
4. 在 AI 问答框中模拟一次「美东现在该不该发货？」→ 展示规则型回答
5. 回到概览

**工作量**: 大（~60 行 JS）

---

### #11 底部 LLM 占位与 Q&A Tab 功能重叠

**现象**: Q&A Tab 已经做了 6 道数据驱动的问答卡（含表格、标签），底部 LLM 区又放了 4 个 prompt chip 和规则型 mock 回答。两个模块本质都是"用数据回答问题"。

**建议**: 路演时把底部 LLM 占位区 `hidden`，避免评委问"这两个有什么区别"。Q&A Tab 的数据表格 + 标签体系已经足够专业。

**工作量**: 极小（1 行 CSS）

---

### #12 body overflow:hidden 可能导致小屏截断

**现象**: `body { overflow: hidden }` 禁止全局滚动。在 1366×768 的笔记本上，中心区域 + 右侧栏高度可能不够，右下角内容被截断且无法滚动。

**修复**: 
- 右侧栏加 `max-height: calc(100vh - 86px)` + `overflow-y: auto`
- center-top 确认已有 `overflow-y: auto`（目前已有）
- 在 768px 断点下测一下实际效果

**工作量**: 小（~3 行 CSS）

## 四、数据清洗计划（采集完成后执行）

当所有 CSV 就位后：

```
清洗步骤
├── 1. 统一日期格式      YYYY-MM-DD，对齐周五
├── 2. 去重              同一日期多条记录→保留最高质量那条
├── 3. 空值规范           空值统一留空（不写 null / N/A / 0）
├── 4. 质量列统一         每条数据标注 A_official / B_public_excerpt / PENDING
├── 5. 交叉对比           SCFI 内部：COMPOSITE ≈ 分航线加权？出入 >10% 标注
├── 6. 编码清理           去 BOM，UTF-8
└── 7. 落盘              输出到 data/raw/ 作为清洗后唯一真源
```

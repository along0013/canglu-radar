## P0 多Agent可视化（最重要）

### 当前问题
demo-v3.html 是单体架构，所有计算/渲染/交互混在同一个 HTML 文件中，用户感知不到"多个智能体协同工作"。

### 设计方案：4-Agent 协同架构

基于 compute.py 的 4 个 JSON 输出，将系统重组为 4 个 Agent：

| Agent | 数据源 | 职责 | 视觉标识 |
|-------|--------|------|----------|
| 📊 指标计算 Agent | `indices.json` | SCFI/CCFI/SCFIS/WCI/FBX 交叉验证 | 蓝色 `#4A90D9` |
| ⚠️ 预警分析 Agent | `metrics.json` | Z分数、百分位、连涨检测、快通道 | 红色 `#FF4757` |
| 🧮 场景成本 Agent | `scenarios.json` | 基础/压力/极端场景，关税影响 | 橙色 `#FFA502` |
| 🎯 决策建议 Agent | `decisions.json` | 航线级建议生成、置信度标注 | 金色 `#F9C74F` |

### 具体实现

**① Agent 状态栏（topbar 下方，44px）**
- 4 个 Agent 胶囊按钮 + 流动箭头（→）
- 运行中显示脉冲动画，完成显示 ✓，等待显示 `…`
- 点击可定位到对应 Agent 的产出区域

**② 每个卡片底部标注来源**
- 一行 `由 预警分析 Agent 计算 · 置信度：B_public_excerpt`
- 带颜色小圆点 + 半透明分割线

**③ 协作流程图（新增 Tab）**
- 纯 CSS 时序图：指标计算 → 预警分析 → 场景成本 → 决策建议
- 每个节点显示数据源、产出物、耗时

**代码思路**：重构 JS，拆为 `AgentMetrics` / `AgentAlert` / `AgentScenario` / `AgentDecision` 四个模块 + `AgentOrchestrator` 调度类。

**预估人天：3 人天**

## P1 产品完整度（六种状态）

当前只有"成功态"（数据硬编码在 `<script>` 中），其他 5 种全部缺失。

### 1. 加载态 — 骨架屏 + 进度条
- 4 个骨架卡片（shimmer 动画）+ 底部进度条
- 分阶段更新：数据加载 25% → 指标计算 50% → 预警 75% → 渲染 100%

### 2. 空态 — 引导文案
- 大图标 📭 + "暂无运价数据" + 加载 Demo 按钮
- 提示 `python3 engine/compute.py` 用法

### 3. 错误态 — 友好提示 + 重试
- 三种错误场景：数据加载失败 / 单航线缺失 / 引擎执行异常
- 每个场景有对应文案 + 重试按钮 + 技术详情折叠区

### 4. 成功态 — 优化信息层级
- 预警徽章动态化（"2红 2黄 0绿"）
- 航线卡片加数据质量角标
- 决策建议加"一键复制"按钮

### 5. 引导态 — 首次使用 3 步引导
- Overlay 高亮 Agent 状态栏 → 预警面板 → 决策建议
- `localStorage` 记录是否已完成引导

### 6. 边界态 — 极端数据不崩
| 边界场景 | 前端处理 |
|----------|----------|
| Z分数 NaN（样本不足） | 显示 "N/A"，tooltip 解释 |
| 全部航线数据缺失 | 退化为空态 |
| 单周插值数据 | 图表虚线连接，tooltip "插值数据" |
| 历史 <4周 | 禁用 WoW 环比 |
| Chart.js 不可用 | 降级纯文本表格 |

**预估人天：2 人天**

## P2 多维智能扩展

当前：检测✅强 / 归因⚠️弱 / 对策✅中 / 预测❌缺失 / 对话⚠️占位

### 1. 归因智能（新增 `engine/attribution.py`）
- 多因子相关性拆解：油价/BDI/CCFI价差/事件驱动
- 前端渲染为"涨价原因拆解"堆叠条形图
- **2 人天**

### 2. 预测智能（新增 `engine/forecast.py`）
- 基于近 4 周 WoW 趋势 + 衰减模型外推 4 周
- Chart.js 虚线延伸 + 置信区间半透明带
- **1.5 人天**

### 3. 对话智能
- 短期：扩展 `mockAsk()` 规则库 4→20+ 条
- 中期：接入 Hermes Agent API，注入 JSON context
- **2 人天**

### 4. 对策智能增强
- 决策建议加"一键复制" + "导出 PDF"
- **0.5 人天**

**预估人天：6 人天**
